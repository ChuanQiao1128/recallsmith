## 9. Closed external action inputs

`ExternalAction`, `DenialPlan`, `WorkerInventory` and `ReleaseBinding` are companion closed input definitions for the validators in sections 4–5. These are future actual-producer wires, never fabricated evidence of capabilities currently absent. ExternalAction records kind/interface/cycle, event, actual launcher/syscall/custodian source, supervisorTask, custodian run/principal/process, sequence, runtimeManifest, policyHash, complete prior input refs, actual outcomes and observedUtc. Each outcome carries operation, target, result, integer exitCode and a separately registered nonempty external transcript reference. Its contextual values and outcome vocabulary must agree with the corresponding actual observation. The fixed supervisor root must independently register both the action envelope and underlying transcript bytes based on witnessing the event; matching self-written fields or hashes cannot self-register it.

The fixed `T/denial-plan.json` is a supervisor-produced DenialPlan pinned to the unchanged parent access protocol, actual launcherIdentity and policyHash. Its required capability/target pairs are exact and unique, must include all parent I3 requirements, and every pair must appear once in the actual DENIAL_OBSERVED record with DENIED and real exit evidence. The fixed `T/worker-inventory.json` is a WorkerInventory containing the supervisor-observed complete pre-freeze task/process/start set. BUILDERS_STOPPED must account for that entire set and prior termination reports, including restart prevention; a custodian cannot choose a smaller set.

Each post-unseal released raw directory has a fixed `release-binding.json` satisfying ReleaseBinding, independently registered by supervisor after witnessing the original private execution and release. It binds role/ordinal, original control/output/workspace/call, all six original hashes, actual runtime, prompt/projection, custodian replay action and seven checksEvidence refs. These original paths are compared to raw bytes as opaque values; no private original path is opened. Each required check references actual registered external replay evidence. Stage C still independently validates the released raw events/result/prompt/schema bytes with the pure adapter predicates; the release binding or booleans are not substitutes for replay.

External action outcome vocabulary is exact: DENIAL has each capability/target DENIED with nonzero exit, plus tools-disabled/all/DISABLED and public-log-inspection/all/NO_LEAK. Freeze uses accept-freeze/<freeze.path>/ACCEPTED; worker stop uses terminate/<taskId>/TERMINATED and prevent-restart/all/BLOCKED; label start uses private-store/<opaque storeId>/CUSTODIAN_CONTROLLED and labels-start/holdout/STARTED; sealing uses private-checks/all/ALL_PASS, quota/holdout/VERIFIED and nonce-entropy/holdout/VERIFIED.
