## 0. Non-negotiables

- **WORKER SAFETY RULE (verbatim in every brief's Constraints):** a worker may run read-only AWS CLI, `terraform init/validate/plan` (plan must be saved with -out and shown as JSON), but NEVER `terraform apply`, `terraform import` (state-changing), `aws ... create/update/delete/put`, `eas`, or any deploy script. The supervisor applies plans after each merge. Each infra brief's verify.sh therefore checks the PLAN (terraform show -json) against an explicit allow-list of resource addresses and actions — nothing else may appear as create/update/delete.
  Clarifications that follow from it: `import {}` *blocks* in `.tf` files are configuration and allowed (they only act at `apply`); the `terraform import` *command* is not. `aws iam simulate-custom-policy` / `simulate-principal-policy`, `aws ssm describe-parameters`, `aws sts get-caller-identity` are read-only and allowed. `dotnet test`, `npm run build`, `bash -n`, `DRY_RUN=1 ./deploy.sh` (packages only, `src_C/deploy.sh:27`) are allowed. `aws lambda invoke`, `aws ssm get-parameter --with-decryption`, `aws rds create-db-snapshot`, `eas channel:create`, `eas update`, `gh secret set`, `gh api -X PUT` are supervisor/owner only.
- **Terraform, not CDK.** Layout (binding, §1.1): `infra/envs/prod` (E01) and `infra/envs/staging` (E10) are the only roots; both call the six modules `infra/modules/{identity,data,edge,api,worker,observability}` — no seventh module (DNS/certs live in `edge`, SSM in `identity`, schedules in `api`). Terraform `required_version = ">= 1.10"` (1.16.3 installed), `hashicorp/aws` `~> 6.0`, `infra/envs/*/.terraform.lock.hcl` committed (resolves 6.66.0 today; never upgraded inside the wave). Provider blocks carry `region` only — no `profile` (CI uses OIDC; humans `export AWS_PROFILE=dev`). `provider "aws" { alias = "use1", region = "us-east-1" }` exists in every root and is passed to `edge` (`providers = { aws = aws, aws.use1 = aws.use1 }`) for the CLOUDFRONT-scope WAF and the CloudFront certificate.
- **Backend** (`infra/envs/prod/backend.tf`, created by E01, byte for byte):
