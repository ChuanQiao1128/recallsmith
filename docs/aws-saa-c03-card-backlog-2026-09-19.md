## 5. 生成过程与没核的

- 大纲来自官方 HTML 版考试指南（当天抓取）；in-scope 118 个服务每个恰好一张服务卡（代码核对）；每条 knowledge bullet 恰好一张概念卡（107 = 107）；每域选择题配额 51 / 44 / 41 / 34 已满足。
- 四个域的 agent 各自独立对照线上 154 张卡；12 张线上卡被两个域同时认领为"已有"，按优先级保留一个、另一个降为"补角度"；4 张跨域重复的模式卡已合并。
- applied 8 live mappings; retire candidates 2
- folded 31 duplicate pattern cards into their siblings (concept / service / MCQ specs are never dropped: overlapping ones are annotated to be written from a different angle)
- 没核的：must_teach 里的具体数字（配额、价格、延迟）是 agent 写的，写题时以 AWS 文档为准；"补角度"的判断依据是线上卡的前 400 字符，不是全文；服务分组统计按关键词匹配。
