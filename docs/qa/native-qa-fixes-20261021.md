## 同步投影的状态模型

实体是“某账号、某卡组的本地进度投影”，不是把账号、钱包、内容安装合成一个状态。

状态：

- `CACHED_ONLY`：远端快照已缓存，当前账号的卡组尚不能解析。
- `APPLICABLE`：内容已就绪，可以合并远端与本地进度。
- `COMMITTED`：合并后的进度已写入请求所属的账号分区。
- `OBSOLETE_SCOPE`：请求期间活动账号已切换；停止向当前视图应用。
- `RETRYABLE_FAILURE`：请求/存储失败，保留现有队列和缓存，由已有重试触发继续。

事件：登录/账号切换、远端 pull 返回、卡组就绪、合并无变化、存储成功/失败、视图订阅/卸载。评分事件 ID 重复是正常输入。

| 起始状态 | 事件 | 结果 | 副作用/拒绝行为 |
| --- | --- | --- | --- |
| 任意 | pull 返回但卡组未安装 | CACHED_ONLY | 写请求账号缓存，不伪称本地进度已恢复。 |
| CACHED_ONLY | 当前账号卡组就绪 | APPLICABLE | Home/Library 的读取路径应用缓存。 |
| APPLICABLE | 合并改变，存储成功 | COMMITTED | 完成持久化后才通知视图。 |
| APPLICABLE | 合并无变化/重复重放 | COMMITTED | 不重复通知，不产生评分或奖励。 |
| 任意在途状态 | 账号切换 | OBSOLETE_SCOPE | 迟到 pull 停止应用；已发出的存储操作仍固定在原账号。 |
| APPLICABLE | 存储失败 | RETRYABLE_FAILURE | 不发成功通知；沿用已有失败/重试机制。 |
| COMMITTED | Home 仍挂载且账号一致 | COMMITTED | 调用现有合并刷新器重算视图；不重新提交评分。 |
| COMMITTED | Home 卸载/账号不一致 | COMMITTED | 不更新该视图。 |

不变量：

1. 账号 A 的请求不能向账号 B 的进度或元数据写入 A 的结果。
2. 视图通知发生在成功写入之后。通知失败不能使同步失败。
3. 模型、阶段、下次复习时间来自同一个胜出评分；旧评分不能覆盖新评分模型。
4. 同一事件去重仍由数据库的事件 ID 约束和同一 ingest 语句保证；不重复计数。
5. 游客内容复用仅限公开免费卡组；学习进度仍经原有事件接管/同步，不把另一账号数据搬过来。
6. 新增状态字段不能改变既有奖励、余额、抽卡或付费权限。

禁止的转换：未落盘先通知、未安装便宣称恢复、用不同评分的记忆模型拼接新日程、迟到响应写入当前新账号、因无模型而补造历史数据、把本地通过直接记为生产缺陷已关闭。

持久化影响：现有移动端账号分区键保持原格式，新增可选参数只为在途同步固定分区。后端迁移 048 仅新增可空列，不删除、不改写历史数据、不加索引。没有模型的旧行继续为空，App 保留仍有效的本地同次模型；下一次新评分上传完整状态。

测试清单：公开内容接管及拒绝条件、安装后缓存重放、持久化后通知、重复重放、卸载订阅、迟到响应、固定账号写入/旧格式迁移、FSRS 六字段恢复、同次模型保留、旧事件拒绝覆盖、非法模型拒绝、事件去重、迁移重跑、旧客户端兼容，均有本地检查。
