# Home refresh and account learning statistics

Home previously refreshed when review progress landed, before the following draw-state sync wrote collection and wallet values. The mounted view could retain the old balance or owned count until navigation. Gamification sync/adoption now invalidates the current account's Home after durable writes; its coalesced refresh rereads both values and checks the starter gate. Account changes clear retained Home inputs. Late responses from another account are rejected, and sync writes pin their storage partition.

Learning statistics now use `devcards:u:<account>:recallsmith:streaks:snapshot:v1`; signed-out sessions use `anon`. Snapshot and session receipts share one JSON record and one per-account serialized write, so duplicate or concurrent completions do not count twice or lose increments. Settings reloads on account changes and rejects an earlier account's delayed read.

Historical unscoped `recallsmith:streaks:*` totals cannot identify their owner. They remain on disk without being assigned to the first account opening this version. New account-specific session totals start at zero on that device. They are local statistics, not cloud-restored history. Guest statistics stay separate; existing adoption of guest learning progress, cards and balances is unchanged. No backend migration or native dependency change is required.

Regression coverage includes mounted-Home wallet/collection refresh, unrelated-account invalidation, obsolete starter actions, late A sync replies after switching to B, A/B/guest statistics, ownerless legacy totals, concurrent and duplicate session completions, failed-write retry and delayed Settings reads. The full mobile Vitest suite and project typecheck pass. The standalone `test:smoke` command has the same 35 compiler diagnostics on unchanged main (ES2020/Error options, React interop and DOM/RN declaration conflicts); those are recorded separately from this fix's passing tests.

Installed-App acceptance must additionally compare the receiving device's Home to durable business values after real backend sync, without changing tabs. Check account-specific Settings values on the same installation, persistence after restart and that existing learning progress/collection/balances remain intact.
