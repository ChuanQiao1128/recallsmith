## Part A · 第一轮各角色单独评审

四方先独立出稿，再碰面。以下是各角色对 5 张图的逐项观察，只记录有争议或可优化的点，已 OK 的部分不展开。

### A.1 产品经理（PM）视角

核心关切：**"这一眼是否说清了今天要我干什么"**，以及是否背离了 §23.7《克制原则》与 §23.8《温和语气》。

**Screen 01 · Home**
- 信息密度偏高，首屏同时塞进：Header + 路线卡（12关/18分钟/2 Boss）+ 进度条 + 两条 CTA + 抽卡按钮 + 重学区红点 + 周柱图 + 三池分布 pill，竖向滚动需要两屏。PRD §29.2 定义了 "90 秒内进门 → 翻 5 张 → 退出" 的首要动线，目前首屏把*抽卡*和*周回顾*放在了同等视觉权重。提议：**Home 只承担"今日"单目标**，周回顾下移到 Me 或 Review 二级页。
- "10 连抽 · 保底临近 · 2 pulls" 文案含糊：2 pulls 是"还差 2 次保底"还是"今天还剩 2 次"？需要统一到 §30.6.1 的 Header 文案表。
- 重学区 "7 张待处理" 是红色 dot。与 §23.7 "不搞焦虑"相左——红点在东亚玩家心里等同于 badge 债务。提议改琥珀色或 🌫️ 中性符号 + "建议今天回顾 3 张"。
- 路线卡 "12 关 / 18 分钟 / 2 Boss" 三个数字并列，用户学不到"Boss = 更难的卡"这一关键语义。Boss 需要微文案（"比常规卡更难 · 记住有额外奖励"），或在 §30.5 Home 页规范加 tooltip。

**Screen 02 · Draw Stage D（开盒结果页）**
- `≥ 1 LEG` 这段看起来像占位残留——"≥"+"1"+"LEG"三种字符 mixing 不美观，且用户不理解。应为 "本次 1 LEG · 3 RAR · 6 COM" 或 "稀有度摘要：1⚡ 3🔷 6⚪"。
- 2×5 卡片网格上的符号（`async` / `<T>` / `=>` / `{}` / `&&` / `??` / `...` / `[]` / `()`）——作为**美术符号**很炫，但**作为卡牌正面**会让用户误以为"一张卡 = 一个符号 = 一个关键字"。RecallSmith 的原子单位是"Q/A/IRL 三段"，不是符号。卡面应显示 *keyword title*（如"解构赋值 Destructuring"），符号降级为装饰背景。对应需修订 §30.5.2 卡片正面规范。
- 双 CTA：「现在就学这 3 张」（主按钮蓝填色）+ 「全部收入明日」（次按钮描边）。"3" 是哪来的？需要一条微文案："系统挑了今日最有价值的 3 张（含 1 ⚡）给你现学"，并和 §33.4 "免费抽卡 → 学 3 张" 对齐。否则用户会以为是任意数字。
- "现在就学这 3 张"作为主按钮——与 §23.7 "不逼迫"的基调有张力。建议主次倒置：**「全部收入明日」= 主（安全）**，**「现在就学这 3 张」= 次（奖励型邀请）**。PM 认为这比逼玩家学更贴 RecallSmith 气质。

**Screen 03 · Level Flipped（翻牌学习页）**
- 底部 4 档评分按钮「再学 / 偏难 / 记住 / 简单」中 **"记住" 默认蓝色填色**——视觉上像预选。用户未点击前就高亮一个答案会误导（FSRS 强调用户*主动*选 grade）。应该四个都是 outline 默认，悬停/按下才填色。
- 快捷键 1/2/3/4 角标已到位，位置好——但要在第一次使用时给一个 tooltip "键盘党可用 1–4 打分"，响应 §23.10 "给老司机一条路"。
- Q · A · IRL tab 切换：当前设计是**tab 栏**，三态并列。但 §30.6.3 的交互是"先 Q → 用户思考 → 揭 A → 可选 IRL"的**线性披露**。Tab 模式破坏了"先想后看"的 active recall 核心。建议 A 默认折叠为"点我看答案"按钮，IRL 默认折叠为"看看现实中怎么用 →"。
- 代码块 VS Code Dark+ 在米色背景上——这条是加分项，完全贴合 §30.6.3 "文档感代码块"规范，**不改**。
- Progress bar + 关 4/12 + lvl #7a3c 三处进度符号共存，有点过剩。lvl #7a3c 可下沉到长按 Header 显示彩蛋位，不占主视觉。

**Screen 04 · Settlement（收工页）**
- 评分分布条显示 "2 再学 · 4 偏难 · 13 记住 · 5 简单" 共 24 张，但 header 写 "过关 12/12 · 17m 42s"。24 张 vs 12 关——是因为一关有 2 张？还是包含了复习卡？用户会困惑。加一行小字解释："24 次评分（12 关，含复习）"或按关分组。
- "淡忘 进入重学区 2 张" 红色——与 §23.8 温和语气矛盾。改为琥珀色 + "2 张淡忘了，明天见面再见"，去掉 red color。
- "明日路线 · 14 关 / ~20m · Boss Generics 线" + "回首页 / 再抽一次"——整段结构太棒，**保留**。可以补充 §33.4 的**免费抽卡触发**钩子：如果今日达成 all easy，这里自动出现 "🎁 明早送你一次免费 10 连" 的 banner。
- 缺少"学会 +2 / 精通 +1 / 新纳入 +3 / 淡忘 -2"这四条心智账本的**视觉 hierarchy**——目前是 4 行并排，但其实**新纳入 +3** 是最有奖赏感的（用户今早抽到的卡第一次上线），应该视觉放大一号或加金色边框。

**Screen 05 · Library（图鉴）**
- 顶部三 tab "我的卡组 3 / 图鉴 127 / 重学区 7"——信息架构和 §32 "5-tab bottom nav" 并存，左右上下双导航，有点冗余。建议顶部 tab 精简到两个："图鉴 / 卡组"，"重学区"挪到 Home 或 Review tab，毕竟它已经是 Home 上有红点的入口。
- 池子选择器 "全部 127 / TS 52/80 / Python 31" 和下面的过滤 chips "全部 / 💎精通 / ⚡LEG / <>RAR / 🌫未抽" **语义混合**：池子是内容范围（scope），chips 里"精通/未抽"是**状态**（state），"LEG/RAR"是**稀有度**（rarity），三个维度挤在一行过滤器里——用户无法理解"精通 + LEG 能不能组合"。建议拆成两行：**状态行**（💎精通 / 🎓学会 / 🪙已抽 / 🌫未抽）+ **稀有度行**（LEG / RAR / COM），可以 AND 叠加。
- 3 列卡片网格——完全符合 v3.0 §31.4 的"3 列不是 4 列"决定，**不改**。
- 未抽卡（🌫️）目前看是纯灰色占位——可以加一个 "⟨?⟩" 符号或"来自 TS 主攻池"的 pool hint，让用户知道*哪里能抽到*，而不是永远神秘。

### A.2 UI 设计视角

核心关切：**色彩节奏、留白、字重、符号系统一致性**。

**跨 5 张的通用观察**
- 羊皮纸金 `#FAF3E0` + 墨黑 `#2A2218` 基调贯穿 4 张，宇宙仪式 `#0B1030` 只用于 Draw——色系分工清晰，**达标 v3.0 §30**。
- JetBrains Mono 只用在 Header 标签（如 `route #8f2c` / `seed #2847a`）和代码块，正文是无衬线，节奏好——**保留**。
- DEFAULT 徽章（Home/Level 两处都有）作为"你在常规模式"的状态提示很聪明。但"DEFAULT"四个大写英文字母放在中文界面里偏硬，且用户不一定理解。建议换成 `常规模式` 或 `日常`，或者直接隐藏，只在切换到特殊模式（如"冲刺周"）时显示一个对立徽章。
- 所有圆角 = 12px，阴影 = 浅而长。一致，**保留**。

**Screen 01 · Home**
- 周柱图 7 根柱子（周一到周日）但没有 Y 轴刻度，用户只能看出"今天比昨天高"这种相对关系。微刻度 "5 / 10 / 15 张" 或顶部加一个 "本周最高 14 张" 的 label 就够了。
- 三池 pill "TS 42% · System Design 12% · Python 8%" ——加起来才 62%，剩下 38% 去哪了？建议加一个 "其他 38%" 或改成 stacked bar。
- Home 主 CTA "10 连抽" 和 Draw tab icon 在底部，**视觉冗余**。PM 和 UI 一致认为：首页 CTA 应该是"开始今日学习"而非"抽卡"，抽卡交给 tab。

**Screen 02 · Draw Stage D**
- 宇宙夜空背景 + 大金卡——气氛到位。但大金卡占掉接近 40% 屏高，下面 2×5 还有 10 张卡——滚动成本大。可以**折叠 2×5**为 "⬇ 展开查看本次 10 张" 的 accordion，默认只显示 LEG/RAR 的英雄位 + "+6 COM" 摘要。这样既有仪式感，也不吞屏。
- `> recall.draw(n=10)` 这个终端 header 配色是宇宙蓝底 + 青色字——符合 §30.2 Ceremony tokens。
- CTA 主次按钮的**色温**：蓝填色主按钮在宇宙背景下视觉上比羊皮纸底版更亮，可能打断仪式气氛。可以把 CTA 区单独切回到羊皮纸底（Draw Stage E "回归日常"分离界），仪式归仪式、日常归日常，节奏更清晰。

**Screen 03 · Level Flipped**
- 米色问答区 + VS Code Dark+ 代码块 + 灰蓝 IRL 卡的**三段色温**很漂亮——MDN/Stripe 的文档感完全到位，**这是 5 张里最成功的一张**。
- 关键词高亮（satisfies / as）使用了琥珀色背景——和后面 4 档评分 "再学"按钮可能用的琥珀 warning 色撞。建议关键词 hl 用薄荷绿或天蓝，避开评分警示色。
- RAR 徽章 + ●●●●○ stage dots 叠在一起——能否把 stage 放到 Header 右侧、徽章放到 Card 缩略图位？让 "这张卡稀有 + 你已掌握 4/5 级" 两条信息分到两个空间层级。

**Screen 04 · Settlement**
- GradeMixBar 4 色水平条（红琥珀绿蓝）——配色 **达标 v3.0 §31.1**。但 12 + 4 + 13 + 5 = 34？不是 24？数学对不上，设计稿上肯定有数据错。UI 和 PM 都建议出稿前加一条校验脚本。
- "session #2847 · closed" header——彩蛋位到位。可以加一条 "用时 17m 42s · 低于平均 22m"的**正反馈 micro-copy**，比冷冰冰的时间数字温度高。
- 右侧 3 个大数字 "91% / 18 / +3" 没有单位前缀（%是有的），但"18"是啥？掌握数？新增数？必须加单词。

**Screen 05 · Library**
- 3 列卡片有的显示完整稀有度边框（LEG 金 / RAR 紫 / COM 灰），有的是 🌫️ 迷雾占位——对比好。但 **stage 点 ●●●○○** 在 3 列小尺寸下挤作一团，**可读性差**。可以改为进度条（0-5）细线，或数字 "4/5"。
- 筛选 chips 的 emoji 混用 💎🎓🪙🌫⚡ <> 等符号——**视觉噪音偏高**。统一到一套：状态用 emoji，稀有度用 icon (⚡RAR 三角/方块)，避免 emoji + unicode symbol 混搭。

### A.3 前端工程师（FE）视角

核心关切：**RN 实现成本、动画性能、可访问性钩子**。

**性能 & 动画**
- Draw Stage D 的宇宙粒子 + 大金卡发光——要留意 §30.3 的红线：**LEG glow ≤ 80pt outer, particles ≤ 40**。第二轮稿没有粒子数据，实现时需 profile。
- Settlement 的 GradeMixBar 如果做 CountUp 动画，要 max 300ms，且支持 `reduceMotion` 跳过到终态。
- Home 周柱图若使用 Reanimated 3 spring，要把 7 根柱子的入场 stagger 控制在 7 × 40ms = 280ms 内，避免打断"开门秒看今日"的节奏。

**Tap target & 可访问性**
- Level Flipped 的底部 4 档按钮要 ≥ 44pt 高、≥ 80pt 宽才符合 iOS HIG + §27 "视障用户" 要求。
- Library 3 列卡片宽度 ≈ 110pt，上面再塞 stage dots + rarity badge 会挤到 tap area < 44pt。建议整卡点击进入详情 = 主操作，徽章 & stage 不要做成独立可点元素。
- 所有带 emoji 的 chip 文案需 `accessibilityLabel` 覆盖（"💎精通" → "精通状态过滤"），否则 VoiceOver 读出 emoji Unicode 名称很糟。

**Theme 切换**
- v3.0 §30 把 Dark Navy 定为**可选 setting**——Screen 02 用宇宙仪式，Screen 01/03/04/05 用羊皮纸金，混用没毛病。但 FE 要注意：**Dark mode 切换不影响 Draw Stage D**，因为 Draw 有独立 Ceremony theme，不跟 Settings dark 联动。需要在 §30.11 交付说明里**明确**。

**国际化**
- "10 连抽"、"关卡"、"重学区"等中文短词——布局上对齐好。切换英文时 "10-pull"、"stage"、"relearn queue" 长度爆涨 1.5–2x。需要预留 **150% 字符膨胀带**在所有 Header/按钮上。

**数据与状态**
- Home 上的"10 连抽 · 保底临近 · 2 pulls"需要从服务端 `pityCounter` 同步——如果用户在 Draw 抽完没 sync 就回 Home，要处理乐观更新。
- Library 的 "127 / 52/80 / 31" 数字要做 `useMemo` + 增量计算，127 张全量 reload 会让低端机卡。

### A.4 用户体验（UX）视角

核心关切：**情绪曲线、认知负荷、仪式感与日常的切换节奏**。

- Home → Draw 的**情绪跨度**最大：日常米色 → 宇宙蓝黑，需要 0.6s 过场动画（§30.7）保护用户不受到"断电"式的颜色切换冲击。目前静态稿看不出过场，需要在 §30.11 明写。
- Draw → Level：用户刚经历高潮，落到"现在就学 3 张"页面，情绪需要**软着陆**。Level Flipped 的米色背景 + "lvl #7a3c" 彩蛋 + 四档评分按钮——都对，但**少了一个"深呼吸"动作**：翻牌前 300ms 的停顿、Header 出现前的 icon 脉动，都可以让"从仪式到学习"的切换更平顺。
- Settlement 页是当日情绪终点。"淡忘 -2" 用红色=**情绪谷底的放大**。改为琥珀色 + 温和文案后，谷底下探深度降低，明日回来的概率升高（行为设计基本功）。
- Library 是**冷设备**页面——用户是在**非学习时段**（坐地铁、睡前）翻看。它不需要高情绪，但需要**低认知成本**。当前过滤 chip 的混搭让"翻图鉴摸鱼"变成了"解密系统"，UX 给 -1。

## Part B · 模拟用户访谈（6 类代表用户）

按 §27 edge tests 中定义的 6 类用户（+ 新 Day-1 新手），每人对 5 张图给 1–2 条最核心反馈。以下对话为角色扮演纪要，不代表真实访谈。

### B.1 一手党 · Linda（做题做到心累那种）

> "我一天要刷 120 张卡，不是来玩抽卡的。Home 上那个周柱图我扫都不扫——我要的是『今天还剩几张』这个数字，越大越好看到。抽卡 CTA 对我来说是负担，我宁愿 Home 直接把我扔进 Review 列表。"

**关键 insight**：Home 应支持**密度模式**切换（Chill / Intense / Rush）或者读取用户"平均每日张数"来自动收紧 UI。§33.1 需要补一个"重度用户"分支。

> "Settlement 那个『明日路线』我不看，我直接『再抽一次』——抽卡对我来说是积攒弹药，不是仪式。我觉得『再抽一次』应该放更大。"

**关键 insight**：Settlement 双 CTA 视觉权重应支持"热键快跳"：keyboard-first 用户应该 1 键 = 回首页，2 键 = 再抽。§30.10 键位补充。

### B.2 证书冲刺党 · Dev（3 周后考 AWS）

> "我要的是『还差多少张全精通』——没看见。Library 进度条只写了 10/30/12/28 四个状态数字，但我需要**截止日倒计时**：3 周内每天至少刷 X 张才能考过。"

**关键 insight**：Library 或 Home 应加一个**目标条**（Goal Bar），支持用户绑定考期/日期，反推每日 quota。需要新增 §34 "学习目标" 模块（v2 功能，PRD 可标 P2）。

> "Draw 那个仪式感我挺喜欢——但抽出来是 `vDOM` 这种我根本不会考的卡，浪费一次。"

**关键 insight**：Draw 的卡池权重应能被用户"锁池"——冲刺期只抽主攻池。§30.6.2 Draw 配置增补"锁池"开关。

### B.3 视障用户 · Ray（iOS VoiceOver）

> "我开 VoiceOver 听 Home——它念『DEFAULT 10 连抽 保底临近 2 pulls』，完全断句错了。还有 chip 里的 emoji 一个个念（『钻石 表情符号 精通 两个字』），太长。"

**关键 insight**：**必须**给每个 chip / badge 加 `accessibilityLabel`，覆盖 emoji 名称。Home Header 要分段朗读。§27 视障 edge test 需升级到"必达"而非"参考"。

> "4 档评分按钮听起来是『再学 偏难 记住 简单』但没说快捷键——我用蓝牙键盘才能操作。"

**关键 insight**：accessibilityHint 补"按 1 到 4 选择"。§30.6.3 键盘交互回写 a11y。

### B.4 减动效用户 · June（有前庭不适）

> "Draw 那个宇宙粒子一飞我头晕。我在 iOS 里开了 Reduce Motion——你们这边跟不跟？"

**关键 insight**：**必须**尊重 `prefersReducedMotion` —— §30.3 红线补充：粒子、发光、CountUp 全部降级为瞬切。FE 落实 `useReducedMotion` hook。

> "Level 翻牌的翻转动画会不会有？如果有我也要能关。"

**关键 insight**：翻牌动画加 reduce-motion 检查。§30.7 动画清单必须附 a11y 降级路径。

### B.5 新手 Day-1 · 小宇（今天刚下载）

> "我进去第一眼就是个『路线 12 关 18 分钟』——什么 12 关？路线是啥？Boss 又是啥？我没准备好。"

**关键 insight**：需要**首次启动引导**（Onboarding 3 页）：抽卡→学习→收工 3 步讲明白。现在 PRD §26 把这个标为 v2 推迟，但**Day-1 流失的成本**可能超过晚推一个月。建议 §26 前置到 v1 MVP。

> "Library 里写『图鉴 127』，但我一张都没有——为啥不是 0/127？"

**关键 insight**：Library 数字应始终 `N/Total` 格式。§30.6.5 改为 "已收集 0 / 127"。

### B.6 Power User · Kai（键盘党 + 深夜刷卡）

> "所有的夜晚刷卡场景，我都希望切到 Dark Navy。但你们把 Dark 藏在 Settings 里——我每天开 app 要点 3 下才到 Dark？"

**关键 insight**：Home Header 右上加**主题快切图标**（日/月），长按 tab 栏任意位也能切。§30.10 交互补充。

### C.2 跨页通用（写入 §30.11 交付说明）

1. **`prefersReducedMotion` 必达**——粒子、发光、翻转、CountUp 全部有降级路径。
2. **`accessibilityLabel` 必达**——所有 emoji / 符号类 chip 必须有语义标签。
3. **i18n 150% 字符膨胀带**——所有 Header / Button / Chip 预留。
4. **Dark theme 不联动 Draw**——Draw Stage D 固定 Ceremony，不跟 Settings Dark 切换。
5. **数字格式约定**——`N/Total` 格式 + 明确单位。
6. **主按钮温度约定**——"邀请型"选择（选学多少）使用次按钮色，"安全型"（全部收入明日）作主按钮，贯穿 §23.7 克制原则。
