# Ceremony SFX — per-file sources and licences
2026-09-20

This file records the source and licence of every ceremony sound effect, one row
per name. The owner fills it in as real samples replace the synthetic placeholders.

## Accepted / rejected licences

- Accepted: `CC0`; `CC-BY 4.0` (attribution text mandatory — copy it into the table
  below AND into the app's credits screen when one exists); `Sonniss` GDC bundles
  (record as `Sonniss royalty-free`, **not** `CC0`).
- Rejected: `CC-BY-NC`, `CC-BY-SA`, "free for personal use", and any unknown licence.
- Format: 44.1 kHz, 16-bit, mono WAV, ≤ 120 KB each; beds must loop cleanly.

## Aliases (today's state)

Today only six files are committed — `whoosh.wav`, `rip.wav`, `card-drop.wav`,
`card-flip.wav`, `shimmer.wav`, and `legendary.wav` — all synthetic placeholders
generated by `mobile/scripts/gen_sfx.py`. `SFX_ALIASES` in
`mobile/src/components/ceremonyAudio.ts` maps every other name onto one of those
six, so the ceremony can reference all 17 names before real files exist. To swap a
real file in: drop it under this directory with the intended name (for example
`crinkle.wav`), change that name's entry in `SFX_ALIASES` to point at itself, then
restart Metro with `-c`.
