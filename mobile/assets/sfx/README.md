# Ceremony SFX + Haptics + Skia install

Three optional libraries unlock the commercial-grade ceremony layer. Each is
guarded — without it the app keeps working, just less polished.

## One-time install (all three)

```bash
cd mobile

npx expo install expo-av           # audio
npx expo install expo-haptics      # vibration
npx expo install @shopify/react-native-skia   # GPU holographic shimmer

npx expo prebuild --clean          # regenerates ios/ + android/
# Then rebuild your dev client:
#   npx expo run:ios
#   npx expo run:android
```

After rebuild, all three layers automatically activate. No code changes needed.

## What each one does

| Library | When it fires | Effect |
|---|---|---|
| `expo-av` | every phase transition + per-card tap | 6 SFX (whoosh / rip / card-drop / card-flip / shimmer / legendary) |
| `expo-haptics` | tear / per-card tap / LEG flash | tick (light), impact (medium/heavy), success (notification pattern) |
| `@shopify/react-native-skia` | rare-card front face during cards-on-table | GPU-rendered diagonal rainbow sweep that travels across the card every 1.6s |

## SFX file locations

- `whoosh.wav` — pack approaching
- `rip.wav` — pack tearing open
- `card-drop.wav` — common card revealed
- `card-flip.wav` — generic per-card tap
- `shimmer.wav` — rare card revealed
- `legendary.wav` — legendary card revealed (long chord)

These are **synthetic placeholders** generated by `mobile/scripts/gen_sfx.py`.
They prove the pipeline works. For shipping quality, replace each `.wav` with
something from a real SFX library:

### Recommended free sources

| Source | Search terms |
|---|---|
| [freesound.org](https://freesound.org) | `card flip`, `card swoosh`, `paper rip`, `magical shimmer`, `chime fanfare`, `whoosh transition` |
| [Mixkit](https://mixkit.co/free-sound-effects/) | `card`, `coin`, `magic`, `success` categories |
| [Zapsplat](https://www.zapsplat.com) | `card draw`, `pack rip` (free signup) |

Keep durations under 1 second except for `legendary.wav` (which can run up to
2s). Anything longer overlaps the next phase awkwardly.

## How to swap

1. Download a `.wav` or `.mp3`
2. Drop it in `mobile/assets/sfx/` with the matching filename
3. Restart Metro with cache clear: `npx expo start -c`

## Troubleshooting

- **App still silent after install**: confirm `expo-av` resolved by running
  `node -e "console.log(require('expo-av').Audio.Sound)"` in mobile/
- **Crash with "Native module not registered"**: forgot to run `expo prebuild`
  + rebuild dev client. Just installing the JS package isn't enough.
- **Skia shimmer doesn't render**: confirm with
  `node -e "console.log(require('@shopify/react-native-skia').Canvas)"`
