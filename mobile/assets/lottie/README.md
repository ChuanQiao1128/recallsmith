# Lottie animations

The ceremony screen optionally plays a Lottie animation during the dramatic
phases (`tear-flip` → `flash-reveal` → `settle`). Without the package
installed, the screen falls back to the hand-rolled `Animated` visuals — so
the app keeps working before you do this install step.

## One-time install

```bash
cd mobile
npx expo install lottie-react-native
npx expo prebuild           # regenerates ios/ + android/
# Then rebuild your dev client:
#   ios:     npx expo run:ios
#   android: npx expo run:android
```

After the rebuild, `CeremonyLottie` automatically detects the package and
takes over the visual layer.

## Files

- `pack-opening.json` — placeholder animation (3s, 30fps) generated by
  `mobile/scripts/gen_lottie.py`. Re-run that script to tweak colours/timing.
- Wherever you want to swap in a "real" animation, replace this file (or
  point `CeremonyLottie` at a different `require()`'d JSON via the `source`
  prop).

## Where to find better animations

[https://lottiefiles.com](https://lottiefiles.com) — search for any of:

- `card pack opening`
- `booster pack`
- `loot box`
- `mystery box reveal`
- `card flip`
- `confetti burst`

### ⚠️ Download the right format

LottieFiles ships **two** download formats. We need the second one:

| Format | What it is | Works? |
|---|---|---|
| `.lottie` (default) | A ZIP wrapper around the real JSON | ❌ — Metro can't bundle ZIPs as JSON; the app crashes with `[runtime not ready]: Compiling JS failed: ... unrecognized Unicode character` |
| `.json` (Lottie JSON / Bodymovin) | The actual animation data | ✅ — drop straight in |

On the LottieFiles download dialog, choose **"Lottie JSON"** (sometimes labelled "Bodymovin"). Don't pick the dotLottie option.

If you already downloaded a `.lottie` file by accident, we can recover it:

```bash
cd mobile
python3 -c "
import zipfile, shutil
with zipfile.ZipFile('assets/lottie/pack-opening.json', 'r') as z:
    # find the real animation file inside
    name = next(n for n in z.namelist() if n.endswith('.json') and 'manifest' not in n)
    with open('assets/lottie/pack-opening.json.tmp', 'wb') as out:
        out.write(z.read(name))
shutil.move('assets/lottie/pack-opening.json.tmp', 'assets/lottie/pack-opening.json')
"
```

(That's exactly what we did to recover from the first crash.)

### Duration

The dramatic phases together are ~2.18s. Anything **2-6s** is fine — the
ceremony screen waits for `onAnimationFinish` before navigating. If your
animation is much longer (>6s) the auto-advance fallback at 6.7s after sequence
start will kick in regardless, so trim or shorten in After Effects.

### Recommended duration

The dramatic phases together are ~2.18s (1300 + 420 + 460 ms). The placeholder
is intentionally a touch longer (3s) so it covers `settle` too. If your new
animation is much longer, the result screen may auto-advance before it
finishes — either trim the animation or extend the auto-advance delay in
`DrawCeremonyScreen.tsx` (the `+ 500` offset on the `autoTimer`).

## Programmatic API

```tsx
import { CeremonyLottie, ceremonyLottieAvailable } from '../components/CeremonyLottie';

if (ceremonyLottieAvailable) {
  // Lottie is installed and the JSON loaded fine.
}

<CeremonyLottie
  ref={lottieRef}
  source={require('./assets/lottie/my-other-animation.json')}
  loop={false}
  onAnimationFinish={() => console.log('done')}
/>;

lottieRef.current?.play();   // restart
lottieRef.current?.reset();  // back to frame 0
```

## Why Lottie instead of more `Animated` code?

Pokemon TCG Pocket / Hearthstone / NBA Top Shot all hand off the high-drama
moments to **timeline animations baked by a designer in After Effects**. Lottie
is the React Native equivalent of that workflow. You will get more polish from
swapping in a designed JSON than from any amount of code we can write against
`Animated.Value` — the API just doesn't expose enough primitives (no shaders,
no real masks, no GPU particle systems).
