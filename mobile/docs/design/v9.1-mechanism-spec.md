# v9.1 Mechanism Spec — Pool Selection Wired to Real Decks

**Status:** Phase 1 contract for codex. Self-contained — codex implements this without consulting any other v8/v9 design doc.

**Goal:** Replace the mock-pool gacha (`src/mock/draw.ts`) with a real wiring that:
1. Pulls cards from the actual installed deck (not a hardcoded array).
2. Filters out cards the user already owns.
3. Uses an SRS-aware selection algorithm so drawn cards bias toward "useful next reveals".
4. Persists ownership per user, per deck.
5. Reframes pity as "guaranteed missing rare/legendary surfacing", not "rarity floor".
6. Handles pool exhaustion (deck collection complete).

**Why:** Today the Draw → Library connection is fictional. A drawn card is a mock object with a rerolled rarity, unrelated to what the user actually has or has studied. v9's product story ("each card is earned") only becomes true once this wiring exists. This is the load-bearing wall under v9.

**Non-goals for Phase 1:**
- No UI changes (UI is Phase 2 of the runbook).
- No new dependencies.
- No changes to ceremony, navigation graph, or other screens beyond what's needed to wire the data.

```ts
import AsyncStorage from '@react-native-async-storage/async-storage';

const OWNED_PREFIX = 'devcards:draw-owned:'; // + slug

// User-scoped key — matches review/storage.ts isolation pattern
async function ownedKey(slug: string): Promise<string> {
  // For Phase 1 simplicity: use 'anon' default. Codex MUST integrate with
  // setActiveUserSubForStorage from review/storage.ts in a follow-up task,
  // tracked in v9.2-todo. For now, single-user behavior is sufficient.
  return `${OWNED_PREFIX}${slug}`;
}

export async function loadOwnedSet(slug: string): Promise<Set<string>> {
  try {
    const raw = await AsyncStorage.getItem(await ownedKey(slug));
    if (!raw) return new Set();
    const parsed = JSON.parse(raw);
    if (!Array.isArray(parsed)) return new Set();
    return new Set(parsed.filter((x): x is string => typeof x === 'string'));
  } catch {
    return new Set();
  }
}

export async function saveOwnedSet(slug: string, set: Set<string>): Promise<void> {
  await AsyncStorage.setItem(await ownedKey(slug), JSON.stringify([...set]));
}

export async function markCardsOwned(slug: string, stableUids: string[]): Promise<Set<string>> {
  const current = await loadOwnedSet(slug);
  for (const uid of stableUids) current.add(uid);
  await saveOwnedSet(slug, current);
  return current;
}

export async function isCardOwned(slug: string, stableUid: string): Promise<boolean> {
  const set = await loadOwnedSet(slug);
  return set.has(stableUid);
}

export async function clearOwnedSet(slug: string): Promise<void> {
  await AsyncStorage.removeItem(await ownedKey(slug));
}
```

## 4. New module: `src/features/gacha/draw/poolSelection.ts`

The core algorithm. Pure function, no I/O — caller passes data in.

```ts
import type { CardExport } from '../../../types/deckExport';
import type { CardProgress } from '../../../review/model';
import { rarityOfCard, RARITY_RANK, type Rarity } from './cardRarity';

export type SelectionInput = {
  deckCards: CardExport[];           // all cards in the deck
  ownedSet: Set<string>;             // stableUids the user already has
  progress: CardProgress[];          // SRS state per card
  drawCount: number;                 // how many cards to surface
  pityState: PityState;              // see §5
  // Deterministic seed for tests; in prod, pass Date.now()
  seed: number;
};

export type SelectionOutput = {
  cards: CardExport[];               // length ≤ drawCount; can be shorter if pool exhausted
  poolExhausted: boolean;            // true if missing pool became empty mid-selection
  pityNext: PityState;               // updated pity counter for caller to persist
  pityFiredFor: 'LEG' | 'RAR' | null; // which rarity was force-surfaced this draw, if any
};

import type { PityState } from './pity';

export function selectDrawCards(input: SelectionInput): SelectionOutput {
  const { deckCards, ownedSet, progress, drawCount, pityState, seed } = input;

  const progressByUid = new Map(progress.map((p) => [p.stableUid, p]));
  const missing = deckCards.filter((c) => !ownedSet.has(c.StableUid));

  if (missing.length === 0) {
    return { cards: [], poolExhausted: true, pityNext: pityState, pityFiredFor: null };
  }

  // ---- Weight each missing card ----
  // Higher weight = higher chance to surface in this draw.
  // Tiers (in order):
  //   3.0 — seen but not owned (lastReviewedAt > 0): "ready to claim"
  //   2.0 — due now or overdue (nextReviewAt > 0 && nextReviewAt <= now)
  //   1.0 — never seen (no progress entry, or no lastReviewedAt)
  // We sample without replacement, weighted.
  const now = seed; // use seed as "now" for determinism in tests; prod passes Date.now()
  type Weighted = { card: CardExport; weight: number };
  const weighted: Weighted[] = missing.map((card) => {
    const p = progressByUid.get(card.StableUid);
    let weight = 1.0;
    if (p && typeof p.nextReviewAt === 'number' && p.nextReviewAt > 0 && p.nextReviewAt <= now) {
      weight = 2.0;
    }
    if (p && typeof p.lastReviewedAt === 'number' && p.lastReviewedAt > 0) {
      weight = 3.0;
    }
    return { card, weight };
  });

  // ---- Pity check: if pity is at threshold and there's a missing LEG, force one in ----
  let pityFiredFor: 'LEG' | 'RAR' | null = null;
  let pityNext: PityState = pityState;
  const forcedCards: CardExport[] = [];

  if (pityState.draws >= pityState.threshold) {
    const missingLeg = missing.find((c) => rarityOfCard(c) === 'LEG');
    if (missingLeg) {
      forcedCards.push(missingLeg);
      pityFiredFor = 'LEG';
      pityNext = { ...pityState, draws: 0 };
    } else {
      const missingRar = missing.find((c) => rarityOfCard(c) === 'RAR');
      if (missingRar) {
        forcedCards.push(missingRar);
        pityFiredFor = 'RAR';
        pityNext = { ...pityState, draws: 0 };
      }
    }
  }

  // Remove forced from weighted pool
  const forcedIds = new Set(forcedCards.map((c) => c.StableUid));
  let remaining: Weighted[] = weighted.filter((w) => !forcedIds.has(w.card.StableUid));

  // ---- Sample remaining slots with weighted selection (deterministic via seed) ----
  const slots = drawCount - forcedCards.length;
  const picked: CardExport[] = [...forcedCards];
  let rngState = seed;

  function nextRandom(): number {
    // mulberry32 — deterministic, fast, no deps
    rngState = (rngState + 0x6D2B79F5) >>> 0;
    let t = rngState;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  }

  for (let i = 0; i < slots && remaining.length > 0; i += 1) {
    const totalWeight = remaining.reduce((s, w) => s + w.weight, 0);
    let r = nextRandom() * totalWeight;
    let pickedIdx = 0;
    for (let j = 0; j < remaining.length; j += 1) {
      r -= remaining[j].weight;
      if (r <= 0) {
        pickedIdx = j;
        break;
      }
    }
    picked.push(remaining[pickedIdx].card);
    remaining.splice(pickedIdx, 1);
  }

  // ---- Update pity counter ----
  // Pity counter increments only if we did NOT surface a LEG in this draw.
  if (pityFiredFor !== 'LEG') {
    const surfacedLeg = picked.some((c) => rarityOfCard(c) === 'LEG');
    if (!surfacedLeg) {
      pityNext = { ...pityNext, draws: pityNext.draws + 1 };
    } else {
      pityNext = { ...pityNext, draws: 0 };
    }
  }

  const poolExhausted = picked.length < drawCount;

  return { cards: picked, poolExhausted, pityNext, pityFiredFor };
}
```

**Test:** `tests/unit/poolSelection.test.ts`
- Excludes owned cards from output.
- Returns at most `drawCount` cards.
- Returns fewer than `drawCount` and sets `poolExhausted: true` when missing pool < drawCount.
- Returns empty + `poolExhausted: true` when missing pool empty.
- Pity at threshold + missing LEG present → forces LEG into output, resets pity.draws to 0.
- Pity at threshold + no missing LEG + missing RAR → forces RAR, resets.
- Pity at threshold + nothing missing rare/leg → pity carries, surfaces only commons.
- Same seed → same output (determinism).
- Weighting: cards with `lastReviewedAt > 0` are statistically more likely to surface than never-seen cards (across many seeds; use a 1000-iteration property test).

Add to `pity.ts`:

```ts
export type PityState = {
  draws: number;       // draws since last LEG surface
  threshold: number;   // when draws >= threshold, force a missing LEG/RAR
};

export const DEFAULT_PITY_STATE: PityState = { draws: 0, threshold: 10 };

export function buildPityProgressLabelV9(state: PityState, missingLegCount: number): string {
  if (missingLegCount === 0) {
    return ''; // no missing LEG to surface — pity has no meaning
  }
  const remaining = Math.max(0, state.threshold - state.draws);
  if (remaining === 0) return 'Next draw guarantees a missing rare or better';
  return `${remaining} draws until guaranteed reveal`;
}

// Per-deck pity persistence
import AsyncStorage from '@react-native-async-storage/async-storage';

const PITY_PREFIX = 'devcards:draw-pity:';

export async function loadPityState(slug: string): Promise<PityState> {
  try {
    const raw = await AsyncStorage.getItem(`${PITY_PREFIX}${slug}`);
    if (!raw) return { ...DEFAULT_PITY_STATE };
    const parsed = JSON.parse(raw);
    if (!parsed || typeof parsed.draws !== 'number') return { ...DEFAULT_PITY_STATE };
    return {
      draws: Math.max(0, Math.floor(parsed.draws)),
      threshold: typeof parsed.threshold === 'number' && parsed.threshold > 0
        ? parsed.threshold
        : DEFAULT_PITY_STATE.threshold,
    };
  } catch {
    return { ...DEFAULT_PITY_STATE };
  }
}

export async function savePityState(slug: string, state: PityState): Promise<void> {
  await AsyncStorage.setItem(`${PITY_PREFIX}${slug}`, JSON.stringify(state));
}
```

- save+load round-trip.
- `buildPityProgressLabelV9` returns empty string when missingLegCount=0.
- Returns "Next draw guarantees..." when remaining=0.
- Returns `${remaining} draws until guaranteed reveal` otherwise.

## 6. Wire it together: replace `buildPoolDrawResult`

`src/mock/draw.ts` currently exports `buildPoolDrawResult(poolId, pityBefore, drawCount)`. This is called from `DrawScreen.tsx` (search the project). Replace it with a new function that uses real data.

Add to `src/features/gacha/draw/drawState.ts` (or create a new `drawCommit.ts` if drawState is too crowded):

```ts
import { resolveDeckBySlug } from '../../../content/deckRepository';
import { loadDeckProgress } from '../../../review/storage';
import { loadOwnedSet, markCardsOwned } from './ownedStore';
import { loadPityState, savePityState, type PityState } from './pity';
import { selectDrawCards } from './poolSelection';
import { rarityOfCard, RARITY_RANK } from './cardRarity';

export type DrawnCardVm = {
  stableUid: string;
  question: string;
  difficulty: number;
  rarity: 'COM' | 'RAR' | 'LEG';
};

export type DrawCommitResult = {
  cards: DrawnCardVm[];
  poolExhausted: boolean;
  pityFiredFor: 'LEG' | 'RAR' | null;
  highlightedRarity: 'RAR' | 'LEG' | null;
  ownedAfter: number;        // collection size after this draw
  totalCards: number;        // deck total
};

export async function commitDraw(slug: string, drawCount: 1 | 10): Promise<DrawCommitResult | null> {
  const deck = await resolveDeckBySlug(slug);
  if (!deck) return null;

  const [progress, ownedSet, pity] = await Promise.all([
    loadDeckProgress(deck),
    loadOwnedSet(slug),
    loadPityState(slug),
  ]);

  const result = selectDrawCards({
    deckCards: deck.Cards,
    ownedSet,
    progress,
    drawCount,
    pityState: pity,
    seed: Date.now(),
  });

  // Persist new owned + pity
  const drawnUids = result.cards.map((c) => c.StableUid);
  if (drawnUids.length > 0) {
    await markCardsOwned(slug, drawnUids);
  }
  await savePityState(slug, result.pityNext);

  const ownedAfter = ownedSet.size + drawnUids.length;

  const cards: DrawnCardVm[] = result.cards.map((c) => ({
    stableUid: c.StableUid,
    question: c.Question,
    difficulty: c.Difficulty,
    rarity: rarityOfCard(c),
  }));

  let highlightedRarity: 'RAR' | 'LEG' | null = null;
  for (const c of cards) {
    if (c.rarity === 'LEG') { highlightedRarity = 'LEG'; break; }
    if (c.rarity === 'RAR') highlightedRarity = 'RAR';
  }

  return {
    cards,
    poolExhausted: result.poolExhausted,
    pityFiredFor: result.pityFiredFor,
    highlightedRarity,
    ownedAfter,
    totalCards: deck.Cards.length,
  };
}
```

**DrawScreen call-site change:** wherever the screen currently calls `buildPoolDrawResult(...)` (or its equivalent), replace with `await commitDraw(slug, drawCount)`. Map the result fields to the existing route param shape (`DrawCeremony` route already has the right shape — see `src/navigation/types.ts` lines 75-93).

`buildPoolDrawResult` in `src/mock/draw.ts` is **not deleted** in Phase 1 — it's left as-is for tests that still reference it. Codex marks it `@deprecated` with a comment pointing to `commitDraw`.

## 7. Pool exhaustion behavior

When `commitDraw` returns `poolExhausted: true`:
- The Draw still proceeds (ceremony plays with whatever cards came back).
- DrawScreen's load logic (Phase 2 UI work) will subsequently show the exhausted state on next entry.
- For Phase 1, the screen state machine just needs to handle "fewer than drawCount cards came back" without crashing. Existing code paths likely already handle this since `cards.length` is read directly.

When the user lands on Draw and `loadOwnedSet(slug).size === deck.Cards.length`:
- Phase 1 only requires that `commitDraw` returns `null` or empty without erroring. UI shows whatever it shows today (likely error/empty state).
- Phase 2 will add proper "Collection complete" UI.
