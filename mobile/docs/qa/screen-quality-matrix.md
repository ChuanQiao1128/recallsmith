## 使用说明
- 本矩阵覆盖 `src/screens/*.tsx` 全量 screen。
- 每行都定义：`purpose`、`primary CTA`、`P0 fail conditions`、`expected testIDs`、`mobile width checks`、`repair scope`。
- `P0` 与 `W-*` 编码见 `docs/qa/screen-quality-rubric.md`。
